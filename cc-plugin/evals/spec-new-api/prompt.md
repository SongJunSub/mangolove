예약 취소 API 를 새로 추가해야 해. POST /api/reservations/{id}/cancel 이고 취소 수수료 계산이 들어가. 구현 들어가기 전에 Spec 문서부터 써줘. 모르는 부분은 가정이라고 표시하고, 파일로 저장하지 말고 답변에 그대로 적어줘.
